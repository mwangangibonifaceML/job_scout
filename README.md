# job_scout
A job pipeline that aggregates job listings from multiple sources and compares them to users CV and recommends whether the user's qualifications matches the jobs requirements..

## Current Status

🚧 Early development

## Planned Features

- CV upload and parsing
- Job scraping
- Job normalization
- Job deduplication
- Candidate profile extraction
- Rule-based job matching
- Semantic job matching
- LLM-powered job analysis
- Job ranking
- FastAPI REST API
- Email notifications
- Docker deployment
- CI/CD with GitHub Actions
